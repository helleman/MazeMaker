MAZE CREATOR AND SOLVER - COMPLETE APPLICATION SPECIFICATION
================================================================================

This document specifies a complete maze generation, solving, and visualization system
consisting of three integrated Python applications. The system creates perfect mazes
using recursive backtracking (DFS), solves them using BFS shortest path algorithm,
and provides both command-line and graphical interfaces.

2. ASCII MAZE FORMAT SPECIFICATION
==================================
All mazes use a fixed-width ASCII character representation where:
- Maze dimensions: N x M cells represented as (2N+1) x (2M+1) characters
- Cells: Odd indices (1,3,5...) contain paths or markers
- Walls: Even indices (0,2,4...) contain wall characters

Character Set:
- ' ' (space)    : Open path/corridor
- '-'            : Horizontal wall
- '|'            : Vertical wall
- '.'            : Wall junction/corner (T-junctions, corners)
- 'S'            : Start position (always on border)
- 'F'            : Finish position (always internal)
- '*'            : Solution path marker (added by solver)

Maze Structure Rules:
1. Always solvable with exactly one unique path from S to F
2. Walls form 90-degree angles only (no diagonal walls)
3. At least one wall in each cardinal direction (N,S,E,W)
4. Border walls must be complete except for path entrances
5. No isolated regions or dead ends without solution path
6. Start (S) always on perimeter, Finish (F) always internal
7. Generated mazes are "perfect" (tree structure, no loops)

Example 3x3 Maze (7x7 characters):
```
.-------.
|S| |F  |
| .-.-. |
|     | |
.---- . |
|     | |
.---  | |
|       |
.-------.
```

3. APPLICATION 1: maze.py - MAZE GENERATOR
=========================================
Command-line maze generator with library functions for integration.

CLI Usage:
./maze.py <rows> <cols> [output_file.txt]

Parameters:
- rows (int): Number of maze cells vertically (1-50 recommended)
- cols (int): Number of maze cells horizontally (1-50 recommended)
- output_file (str, optional): Save maze to file, otherwise print to stdout

Library Functions:
def generate_maze(rows: int, cols: int) -> List[List[str]]:
    Returns 2D list representing the maze grid

def print_maze(grid: List[List[str]]) -> None:
    Prints maze to stdout in ASCII format

Features:
- Randomized recursive backtracking (DFS) algorithm
- Perfect maze generation guarantee
- Automatic border wall construction
- Random start position on perimeter
- Random finish position in internal cell
- Input validation and error handling
- File I/O with UTF-8 encoding

Error Conditions:
- Invalid dimensions (< 1): "Maze dimensions must be positive integers"
- Non-integer input: "Rows and columns must be positive integers"
- Generation failure (rare): "Failed to generate solvable maze"

Example Usage:
```bash
# Generate and print 10x10 maze
./maze.py 10 10

# Generate and save 20x15 maze
./maze.py 20 15 large_maze.txt
echo "Maze saved to large_maze.txt"
```

4. APPLICATION 2: solver.py - MAZE SOLVER
=========================================
Command-line maze solver with animation and library functions.

CLI Usage:
./solver.py <input_maze.txt>

Parameters:
- input_maze (str): Path to maze file generated by maze.py

Library Functions:
def read_maze(filename: str) -> Tuple[List[List[str]], int, int]:
    Reads and validates maze file, returns grid, height, width

def solve_maze(grid: List[List[str]], start: Tuple[int,int],
               finish: Tuple[int,int], height: int, width: int) -> List[Tuple[int,int]]:
    Returns list of (row,col) coordinates representing shortest path

def print_maze(grid: List[List[str]]) -> None:
    Prints maze grid to stdout

def animate_solve(grid: List[List[str]], path: List[Tuple[int,int]]) -> None:
    Animates solution path by printing updated maze frames

Features:
- BFS (Breadth-First Search) for guaranteed shortest path
- Real-time animation showing '*' path construction
- Comprehensive maze validation
- Automatic size detection from file
- Output file generation: solved_<input_filename>.txt
- Screen clearing and cursor positioning for smooth animation

Validation Checks:
1. File exists and readable
2. Consistent line lengths (rectangular grid)
3. Valid character set: [ -|.|SF*]
4. Exactly one 'S' and one 'F' position
5. Border integrity (walls present with path openings)
6. Path connectivity (S reaches F)
7. No invalid characters or malformed structure

Error Conditions:
- File not found: "File 'filename' not found"
- Invalid format: "Inconsistent line lengths in maze"
- Invalid characters: "Invalid character 'X' in maze"
- Multiple markers: "Multiple 'S' found"
- Unsolvable: "Maze is unsolvable from start to finish"

Animation Details:
- Screen clears between frames (ANSI escape codes)
- '*' character traces path from S to F
- 100ms delay between moves (0.1 seconds)
- Final frame shows complete solution with all '*' markers
- Leaves solved maze visible after completion

Example Usage:
```bash
# Solve maze with animation
./solver.py mymaze.txt
# Output: solved_mymaze.txt created

# In a script
python3 solver.py maze.txt && echo "Solution complete!"
```

6. FILE FORMAT SPECIFICATIONS
============================
All maze files use plain text UTF-8 encoding with Unix line endings (LF).

Maze File Format (.txt):
- Rectangular grid of characters (all lines same length)
- No header or metadata (size auto-detected)
- Each line terminated by single newline (LF)
- No trailing spaces or empty lines
- File size: (height * (width + 1)) bytes approx.

Example File Content (5x5 maze, 11x11 chars):
```
|---------|
|       | |
| . .-. . |
| |   |   |
| .-. .-. |
|S|   | | |
| . .-. . |
| |   |   |
| .-. .-.-|
|   |  F  |
|---------|
```

Solved File Format (solved_*.txt):
- Identical to maze format but with '*' characters
- '*' placed along solution path from S to F
- All other validation rules identical
- Generated automatically by solver.py or GUI.py

File Naming Conventions:
- Maze files: Any name ending in .txt
- Solved files: solved_<original_filename>.txt
- No spaces in filenames (underscores recommended)
- Avoid special characters in filenames

7. ALGORITHM DETAILS
===================
Maze Generation (Recursive Backtracking / DFS):
1. Initialize grid with all walls ('#')
2. Set border walls ('-', '|', '.')
3. Start at random cell (odd coordinates)
4. Mark current cell as visited, set to ' '
5. Randomly select unvisited neighbor
6. Remove wall between current and neighbor
7. Recur to neighbor cell
8. Backtrack when no unvisited neighbors
9. Continue until all cells visited
10. Place 'S' on random border opening
11. Place 'F' on random internal open cell
12. Validate connectivity (BFS from S to F)

Maze Solving (Breadth-First Search / BFS):
1. Read and validate maze file
2. Locate 'S' and 'F' positions
3. Initialize queue with start position
4. Track parent pointers for path reconstruction
5. Explore neighbors (up, down, left, right)
6. Valid moves: ' ', 'S', 'F' characters only
7. Mark visited to prevent cycles
8. Continue until F reached or queue empty
9. Reconstruct path by backtracking parents
10. Validate path length and connectivity

GUI Scaling Algorithm:
1. Get current canvas dimensions
2. Calculate available space (minus 20px margins)
3. Determine cell size: min(available_width/width, available_height/height)
4. Apply constraints: 8px <= cell_size <= 25px
5. Calculate scaled dimensions: width * cell_size, height * cell_size
6. Calculate offsets: (canvas_width - scaled_width)/2, (canvas_height - scaled_height)/2
7. Render all elements using scaled coordinates
8. Update on resize events

8. ERROR HANDLING AND VALIDATION
===============================
Input Validation:
- Command-line arguments: Type checking, range validation
- File paths: Existence, readability, write permissions
- Maze dimensions: Positive integers, reasonable limits (1-50)
- File formats: Character set validation, structure checking

Maze Validation Checklist:
[X] Rectangular grid (all lines same length)
[X] Valid character set: [ -|.|SF*]
[X] Exactly one 'S' and one 'F'
[X] Border walls present (with path openings allowed)
[X] Internal structure valid (no floating characters)
[X] Path connectivity (S reaches F via valid moves)
[X] No isolated regions
[X] Proper wall alignment (90-degree angles)

Error Messages:
- User-friendly with clear explanations
- Exit codes: 0=success, 1=error
- GUI popups for visual feedback
- Console logging for debugging
- Graceful recovery where possible

Exception Hierarchy:
- ValueError: Invalid input/parameters
- FileNotFoundError: Missing input files
- IOError: File access problems
- IndexError: Array bounds violations
- RuntimeError: Algorithm failures (rare)

Batch Processing Example:
```bash
#!/bin/bash
# Generate multiple mazes
for size in 5 10 15 20; do
    ./maze.py $size $size "maze_${size}.txt"
    ./solver.py "maze_${size}.txt"
    echo "Completed ${size}x${size} maze"
done

# Count solved mazes
ls solved_*.txt | wc -l
```

Integration in Other Applications:
```python
# Import as library
from maze import generate_maze
from solver import solve_maze, read_maze

# Generate maze programmatically
grid = generate_maze(8, 8)
print("Generated maze:")

# Solve programmatically
maze, height, width = read_maze("test.txt")
start = next((i,j) for i in range(height) for j in range(width) if maze[i][j] == 'S')
finish = next((i,j) for i in range(height) for j in range(width) if maze[i][j] == 'F')
path = solve_maze(maze, start, finish, height, width)
print(f"Shortest path: {len(path)} steps")
```
